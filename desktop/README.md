# GT-BMS لسطح المكتب (غنو/لينكس)

رفيق تطبيق الهاتف على الحاسوب، **للقراءة فقط** مثله. قيد الإعداد (0.1).

## ما يفعله
- **مباشر** بالزر الأوسط، و**البطارية** بتبويباتها (الخلايا، التقارير، الإشعارات)، و**الإعدادات** بأقسامها، كما في الهاتف.
- مراقبة الشحن وتوقعاته، ومنبهات بنافذة وسط الشاشة وإشعار نظام بزرّين.
- **المزامنة مع الهاتف** على شبكة البيت فقط برمز اقتران: تقارير الهاتف هنا، وشحنات الحاسوب هناك، وحدود البطارية ومنبهاتها.
- استيراد نسخة الهاتف الاحتياطية (ZIP)، وتصدير CSV.
- الاتصال المباشر بالبطارية عبر البلوتوث (BlueZ): **لم يُنجز بعد**.

## الفصل عن تطبيق الهاتف
| | الهاتف | الحاسوب |
|---|---|---|
| الوحدة | `app/` | `desktop/` |
| المنطق المشترك | `core/` | `core/` |
| الإصدار | `app/build.gradle` (vX.Y.Z) | `desktop/build.gradle` (0.x) |
| وسم GitHub | `vX.Y.Z` (الأحدث) | `desktop-vX.Y.Z` (لا يُعلَّم «الأحدث» أبداً؛ محدِّث الهاتف يتجاهله) |
| الحزم | `GT-BMS-vX.Y.Z-release.apk` | `gt-bms-desktop_X.Y.Z_amd64.deb`، `GT-BMS-desktop-X.Y.Z-x86_64.AppImage` |
| سجل التغييرات | `CHANGELOG.md` | `desktop/CHANGELOG.md` |
| بيانات المستخدم | داخل الهاتف | `~/.config/gt-bms/` و`~/.local/share/gt-bms/` |
| بناء F-Droid (`-Pfdroid`) | يُبنى | لا يُضمَّن ولا تُنزَّل مكتباته |

## البناء
```
./gradlew :desktop:run                 # تشغيل
./gradlew :desktop:packageDeb          # desktop/build/compose/binaries/main/deb/
./gradlew :desktop:packageAppImage && desktop/packaging/make-appimage.sh   # desktop/build/appimage/
```
Java مضمّنة في الحزمتين. للتجربة دون بطارية: الإعدادات › المصدر › «محاكاة شحن».
